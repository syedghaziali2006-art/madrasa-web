# مدرسہ صاحب الزمان (عجل اللہ تعالیٰ فرجہ الشریف) — مکمل سسٹم گائیڈ

اس پروجیکٹ میں مدرسہ کی مرکزی ویب سائٹ (Frontend)، مکمل RESTful API (Backend)، اور جدید ایڈمن کنٹرول پینل (Admin Panel) تیار کیا گیا ہے۔

---

## 🚀 سرورز چلانے کا طریقہ (How to Run)

### ۱. بیک اینڈ سرور چلانا (Start Backend API)
ایک نئے ٹرمینل میں درج ذیل کمانڈز چلائیں:
```bash
cd backend
npm install   # (پہلے سے پیکجز انسٹال ہیں)
npm run dev   # یا: npm start
```
* **بیک اینڈ پورٹ**: `http://localhost:5000`
* **ہیلتھ چیک**: `http://localhost:5000/api/health`

### ۲. فرنٹ اینڈ اور ایڈمن پینل چلانا (Start Frontend & Admin Panel)
دوسرے ٹرمینل میں درج ذیل کمانڈز چلائیں:
```bash
cd frontend
npm run dev
```
* **مرکزی ویب سائٹ**: `http://localhost:3000`
* **ایڈمن لاگ ان پورٹل**: `http://localhost:3000/admin/login`

---

## 🔐 ایڈمن لاگ ان کی تفصیلات

* پہلے سے پیدا ہونے والے ایڈمن اکاؤنٹ کے لیے **ای میل** اور **پاس ورڈ** کو `backend/.env` یا سسٹم کی ماحولیات میں سیٹ کیا جا سکتا ہے۔
* اگر کوئی ڈیفالٹ سیٹ اپ موجود ہے تو اسے سیکیورٹی کے لیے ناقابلِ مشاہدہ رہنے کے لیے سختی سے چھپایا جاتا ہے۔
* لاگ ان کے بعد **عمومی ترتیبات** میں پاس ورڈ اپ ڈیٹ کیا جا سکتا ہے۔

---

## 🛠️ سسٹمز اور فیچرز (Features Overview)

### ۱. بیک اینڈ آرکیٹیکچر (`/backend`)
* **Node.js & Express**: ماڈیولر اور فاسٹ REST API
* **JSON File-Based Database**: بغیر کسی بیرونی ڈیٹا بیس سیٹ اپ کے، خودکار ڈیٹا بیس جو ڈیٹا محفوظ رکھتا ہے (`/backend/src/data/*.json`)
* **سیکیورٹی**: JWT (JSON Web Tokens) اور پاس ورڈ ہیشنگ بذریعہ `bcryptjs`
* **فائل اپلوڈ**: Multer کے ذریعے تصاویر اور دستاویزات کی اپلوڈنگ (`/backend/uploads`)
* **اینڈ پوائنٹس**:
  - `/api/auth`: لاگ ان، پروفائل اور پاس ورڈ تبدیلی
  - `/api/admissions`: آن لائن داخلہ فارمز جمع کرنا اور ان کی کیفیت (Pending/Approved/Rejected)
  - `/api/books`: کتب خانہ کی کتب، سرچ و فلٹرز
  - `/api/book-requests`: کتب کی فرمائشیں اور عطیات
  - `/api/staff`: اساتذہ اور عملہ کی تفصیلات
  - `/api/gallery`: کیمپس، لائبریری، پکنک اور تقاریب کا میڈیا
  - `/api/donations`: بینک اکاؤنٹس اور عطیہ دہندگان کی رسیدوں کی تصدیق
  - `/api/settings`: مدرسہ کا پتہ، فیس، نوٹس بورڈ
  - `/api/stats/dashboard`: ڈیش بورڈ میٹرکس

### ۲. ایڈمن کنٹرول پینل (`/frontend/src/app/admin`)
* **ڈیش بورڈ خلاصہ (`/admin`)**:
  - کل داخلے، منظور شدہ طلبہ، کتب خانہ کا ذخیرہ، موصولہ عطیات اور حالیہ درخواستیں
* **داخلہ درخواستیں (`/admin/admissions`)**:
  - تمام طلبہ کی درخواستوں کی لسٹ، سرچ، فلٹرز
  - تفصیلی موڈل: انٹرویو شیڈول کرنا، اسٹیٹس اپ ڈیٹ کرنا، پرنٹ ایبل سلپ
* **کتب خانہ (`/admin/books`)**:
  - نئی کتاب شامل کرنا، ایڈٹ، ڈیلیٹ
  - طلبہ کی فرمائشیں (Book Requests) اور عطیاتِ کتب (Book Donations) کی مانیٹرنگ
* **اساتذہ و عملہ (`/admin/staff`)**:
  - حوزوی، قرآنی اور عصری اساتذہ کا اندراج، اسناد، تجربہ اور تصاویر
* **میڈیا و گیلری (`/admin/gallery`)**:
  - کیمپس، پکنک، کھیل کود اور تقریبات کی تصاویر اور ویڈیوز کا انتظام
* **عطیات و بینک اکاؤنٹس (`/admin/donations`)**:
  - بینک اور والٹ اکاؤنٹس کا انتظام
  - صارفین کی جمع کردہ رسیدوں اور ٹرانزیکشنز کی تصدیق
* **عمومی ترتیبات (`/admin/settings`)**:
  - فیس اسٹرکچر، اعلانیہ پٹی (Notice Marquee)، اور ایڈمن پاس ورڈ تبدیلی
